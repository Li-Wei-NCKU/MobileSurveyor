    📖 鍵盤測量員外業實務指南

    1. 儀器腳螺旋定平口訣（左手大拇指原則）

    「雙手相對向內或向外轉動腳螺旋，氣泡移動方向與左手大拇指同向」。先旋轉 A、B 兩腳螺旋使氣泡移至垂直線上，再旋轉第三個 C 腳螺旋將氣泡推入正中央圓圈。

    2. 水準測量前後視距等長平衡（消除球差與折光差）

    水準測量中，保持前後視距相等（D後視 ≈ D前視）可完全消除地球曲率誤差與大氣垂直折光誤差（地球曲率與大氣折光誤差 c + r 影響），為一等精密水準必備規範。

    3. 航測對空標誌 (GCP) 佈設要領

    航測對空標誌應選在平坦開闊、無樹冠與建物遮蔽之開闊地表，噴塗高反差黑白棋盤或十字標，中心打入鋼釘，並以 GNSS RTK 採集毫米級精確三維坐標與現場點誌記照片。

    4. 無人機航拍正射影像 (UAV Photogrammetry) 重疊率規範

    產製航測正射影像時，航向重疊率（Forward Overlap）通常需設定 ≥ 75% ~ 80%，旁向重疊率（Side Overlap）需 ≥ 65% ~ 70%，以確保空中三角測量（空三解算）具備充裕的同名特徵點進行立體幾何匹配。
