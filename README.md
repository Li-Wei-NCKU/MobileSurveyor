# 鍵盤測量員 手機版 (2.5D) m0.5

桌機版 v5.0 的手機移植：**同一個世界、同一套故事與分支**，只換掉操作方式。

- **2.5D 斜俯視**：沿用原本的 3D 世界與模型，相機固定在玩家斜上方跟著走（寶可夢 3DS 風），地圖與桌機版完全一致
- **點地走路**：點地面就自動尋路走過去；點設備／車／人會走到旁邊自動互動
- **平視器材架**：點器材室的貨架（或架上的設備），鏡頭會滑到架子正前方平視，同時跳出一張架子插畫 —— 三層板子、每格一張設備圖，點圖就拿起來、點空格就放回去；拿了會自動走出器材室，才看得到車子
- **沒有鍵盤鍵帽、沒有常駐喝水鍵**：動作列只留當下真的能做的事；渴了就去點那箱礦泉水（地上或後斗），選「喝一瓶」
- **任務指引**：畫面下方一直有一條「下一步要去哪、多遠」，點它就自動走過去並直接做那件事（開器材架、撿設備、開車門選單）；目標地點在場景裡用黃圈＋箭頭標出來，穿牆也看得到
- **點貨車跳選單**：上車駕駛／看後斗／把手上的東西放上後斗，不用再分車頭車尾瞄準
- **說明文字觸控化**：原本的「按 E」「WASD」等鍵盤說明，在手機版會自動改寫成點選說法
- **指北針**：右上角的轉盤標出東南西北（開車、運鏡時會跟著轉）；點它可以調鏡頭遠近
- **鏡頭可縮放**：預設比先前拉近，畫面上兩指撐開／收合即可縮放，設定會記住
- **對話選錯會講**：小朋友那種限時對話選錯時，會把你選的標 ✗、正確的標 ✓ 並說明，不會讓你不知道自己錯在哪
- **儀器操作改回合制**：定心定平、量天線斜高、手簿觀測都變成指令選單，判斷對錯的地方（陷阱）全部保留，而且一樣不提示
- **開車與後斗保留小遊戲**：方向盤滑桿＋油門／煞車；後斗改成「點一下預覽、再點一下放下」
- **存檔**：格式與桌機版相同，另外多了瀏覽器內的 3 格快速存檔
- **測試工具**：長按左上角的提示列 1.2 秒（或網址加 `#debug`）叫出 F9 面板

目前完成度：**框架＋第一天（GNSS 靜態觀測）全部可玩**，第二、三天的程式都還在，但還沒改成觸控／回合制。

玩法：把 `鍵盤測量員_手機版_m0.5.html` 傳到手機，用瀏覽器打開即可（建議直式）。

開發：`npm install` 後 `npm run dev`；`npx tsc --noEmit -p . && npm run build` 產出 `dist/index.html`。
詳細的移植設計寫在 `PLAN.md`。

## 第一天：GNSS 靜態觀測
接派工單 → 在公司器材室判斷要帶哪些設備、搬上後斗（有格位與堆疊規則）→ 開車到現場（有導航線與路口指示牌，車上可以聽廣播）→ 卸貨（被壓住、擋住的要先搬開）→ 架設三腳架、基座、接收儀 → GNSS 靜態觀測 → 收工清點裝車 → 開回公司 → 成果報告書與考評（工讀生／助理工程師／工程師／外業組長）。

- 儀器操作直接在 3D 場景裡：定心定平（光學對點器、圓水準器即時小視窗）、鋼捲尺量天線斜高、手簿靜態觀測
- 現場事件：路人阿伯（對話有分支，後果不同；選錯會被他拿手機拍照）、土狗衝向腳架（速度很快、揚起塵土；跑到腳架前的黃圈裡就擋得住）、小朋友衝向腳架（Boss 登場運鏡；他們跑到你身邊就自動進 QTE，要連續按對才打發得走）、地主或里長要看公文（頂撞的話會報警：警車鳴笛開到現場，警察下車找你問話，沒公文或頂撞警察就要停工更久）、收工時阿姨騎機車來問地界（答應幫忙會被帶去看界樁，亂動界樁鄰居會衝過來）、回程組長來電
- 外業要喝水：水分歸零會口渴、走得慢

## 第二天：一等水準測量（完成第一天後解鎖）
縣道路肩 BM-1035 → BM-1036，電子水準儀配條碼尺（自動讀數）。兩個水準點上方有起點／終點箭頭，HUD 顯示到 BM-1036 的距離。

全程兩站：第一站你架、第二站學弟架。出發前可以叫學弟幫忙搬設備上車，但他常常少搬一件或多搬一件；搬完他會跑來問「要不要檢查一下」，可以打開後斗看，或選擇相信他。
1. 把標尺、尺墊交給學弟（每次隨機：敬翔、李暐、宏斌、育維、品旭），他去 BM-1035 立尺
2. 第一站自己操作：扛腳架到藍圈附近（建議架站位置，不會自動吸過去，距離是你實際站的位置）架站 → 裝水準儀、定平 → 望遠鏡對準條碼尺、調焦（A/D、Q/E）→ Enter 量測後視 → 看著地上的綠圈按 E，叫學弟到轉點 TP1 立尺 → 量前視
3. 學弟想操作儀器，換你扶尺：學弟扛儀器到第二站架站、定平、量測；你負責扶直標尺（WASD 把尺上的氣泡壓在圈裡），後視讀完拿起標尺走到 BM-1036 立尺
   - 視線會被樹、電線桿、車子擋住（電子水準儀顯示 E 323）：第一站指定前視之前，站在儀器旁按 R 可以扛起來換位置
4. 手簿自動算閉合差（限 3 mm）
5. 收工：學弟扛腳架、水準儀和手簿回車上裝好；你一手標尺、一手尺墊，自己放上後斗（放好一件會自動換另一件）

- 交通錐：路肩作業要擺，但遊戲不告訴你擺哪裡。拿著交通錐看著地面按 E 會往來車方向排一排；要擺在作業區後面、來車的方向才算數，沒帶的話可以回公司拿，或請警察通融（開勸導單，但會借你三角錐）；擺錯了警察一樣會停下來念你、要你重擺（擺錯的那排可以按 E 收起來重擺，重擺還是錯的話他會繼續念）。按 G 只是放地上
- 現場事件：
  - 學弟出包：尺立在 BM-1035 標石旁邊的地上（讀數會差 28 cm），要自己發現（約七成機率發生，主角會冒出一句「好像哪裡怪怪的」），對學弟按 E 糾正
  - 機車停在你和 BM-1035 之間（好好講他會移走；講不好就賴著不走，只能扛起儀器到旁邊的藍圈重新架站）
  - 大貨車經過：望遠鏡畫面會抖、補償器擺動，急著讀會偏掉 1～3 mm
  - 第一天的小朋友回訪：交換角色後 TP1 只剩標尺和尺墊，被攔過的小朋友會來幫忙顧，其他的會跑去踢尺墊（靠近自動 QTE）；尺墊被踢動就要從 BM-1035 整條重測
  - 學弟尺沒扶直（Y 叫他扶好）、轉點沒放尺墊標尺會下陷、第一天的阿伯和阿黃回訪

## 第三天：航測控制點佈設＋航拍（完成第二天後解鎖）
出公司左轉往西約 100 公尺、縣道北側的農地（「福德祠」指示牌右轉進水泥農路）。這塊地每天都在（第一、二天開車往西也看得到），世界地圖不會因為換關而改變。航測範圍只畫在平板上（Q 開關），地上沒有任何提示。

1. 備料：模板、噴漆、鐵鎚鋼釘、RTK、工具袋（無人機已在後斗）。可以叫學弟幫忙搬：隨口交代的話他照樣常常少搬或多搬一件；嚴肅交代他拿清單，他會照派工單一樣一樣打勾、不會搬錯，還會把後斗裡用不到的東西（例如全站儀）放回架上；也可以全部自己來
2. 到現場學弟會走到車尾，自己從後斗拿模板、鐵鎚、RTK（捧在手上），你去車尾拿噴漆箱；拿到噴漆後學弟會問你要佈在哪
3. 自己選 4～5 個點，看著地面按 E 開始佈標（手上拿著噴漆以外的東西、或在停車的地方按 E，就是把東西放下），每個點都是 3D 近距離操作：
   - 鋪模板：模板和遮板一起放，遮板一開始就蓋住對角兩格；滾輪或 A/D 轉方向，Enter 放好（還沒噴之前 Esc 可以反悔）
   - 噴白漆：露出來的兩格噴白。按住左鍵噴，滾輪調噴罐高低（越高越開、越淡、越容易被風吹偏），模板木框會接住一點，噴到框外就是溢漆
   - 換黑漆：遮板可以按 R 轉 90°，轉不轉、轉幾次自己決定，轉錯了就會噴到白格上
   - 掀開模板，中心敲鋼釘：指針走到綠色那格再敲，偏了釘子會歪，歪超過 6° 要按 R 拔起來換一根（偶爾會敲到手指）
4. 噴漆有限量，土上噴漆會被吃掉（又淡又費漆），釘子也會鬆
5. 每個點還要：
   - RTK 測坐標：對著標按 E（RTK 在手上、學弟身上或附近地上），WASD 把對中桿氣泡壓在圈裡，手簿出現「固定解」再按 Space 記錄 3 筆。樹下一直是浮動解（等很久可能跳成固定，但那是假固定），牆邊固定得很慢、精度差；遊戲不提示，看手簿自己判斷
   - 點位照片：C 拿出手機、Space 拍。近照：站在標旁邊、標在畫面中間；遠照兩張：離標 5～40 公尺，畫面裡要有參考地物（廟、農舍、大樹、電線桿、指示牌……），被擋住拍不到
   - 按 Q 打開外業地圖（航測範圍），下方列出每個點的 RTK 和照片狀況；第三天左下角操作列會顯示 Q 外業地圖、C 手機拍照、J 手簿
   - 佈標、RTK、拍照時畫面上方有大字步驟指引（佈標會標出 1 鋪模板 → 2 噴白 → 3 噴黑 → 4 敲鋼釘 目前在哪一步）
6. 佈好 4 點以上跟學弟說收工，他會把佈標的東西拿回車上（早上交代得隨便的話，他可能把鐵鎚忘在某個標旁邊，回公司才發現，要開回去拿或回報遺失）
   - 材料有限：白漆、黑漆、一盒 7 根鋼釘（外業手簿上看得到剩多少）。移點、被沖掉重佈、釘歪換釘都會多用，用完了就沒得釘
7. 下午航拍（航高 30 m，一張照片涵蓋 20 × 15 m）：
   - 從後斗拿無人機箱，找空曠的地方對地面按 E 架起降點（樹下、田裡有作物的地方不能放；太靠近電線桿的話，起飛時指南針會受干擾、飛機亂飄，要自己用 WASD 穩住——遊戲不提示）
   - 對著無人機按 E 打開平板畫航線：在地圖上一個一個點出航點，按住航點可以拖拉調整（對著航點按右鍵刪那一點，Backspace 刪最後一個），平板上有 S 型航線的範例；拍照間距決定前後重疊、航線間距決定側向重疊（需求：前後 ≥ 80%、側向 ≥ 70%），即時顯示兩個重疊率、範圍覆蓋和航線長度；滑鼠移到地圖上會預覽「一張照片」在地上的範圍
   - Space 上升到 30 m 後自動照航線飛、定距拍照；地上會即時畫出照片涵蓋範圍，以及四個角到飛機的連線；規劃的航線用黃色虛線畫在地上，前幾張照片的範圍會留一下，看得出重疊
   - 途中大冠鷲會來一次，QTE 按出畫面上的鍵：每過一關飛機真的會往上拉／往旁邊閃／穩住；失敗會被撞偏，接下來幾張照片會糊
   - 飛到一半，村裡的阿嬤會走過來拍你肩膀問「你在拍我家喔？」（飛機先懸停）
   - 飛完自動回到起降點上空，WASD 對準、Shift 下降
8. 對著無人機按 E 收起來，東西都裝回車上開回公司
9. 回到公司走到器材室工作桌上的電腦（按 E）：① 匯入照片 ② 匯入控制點坐標 ③ 空中三角測量，跑完才看得到正射影像和報表：
   - 正射影像是真的從上面拍的，沒拍到的地方是黑的
   - 控制點太少或誤差太大，整張會歪七扭八；重疊率不夠的地方會接不起來、破圖
   - 每個控制點看不看得到、RTK、殘差，空三平差 RMSE（規範 ≤ 10 cm）
   - 按「交差」才出最後的成果報告

成果報告會算：分布（四角＋中央有沒有可用的點、點有沒有太擠）、點位選擇（範圍外、樹下、農路上、別人的田裡、土上、廟埕）、標誌品質（噴漆覆蓋、溢漆、鋼釘傾斜、腳印／輪胎痕／被沖掉）、RTK 坐標（固定解、假固定、桿子歪）、點位照片、航拍飛行（重疊率、覆蓋、指南針、大冠鷲、降落）、空三平差 RMSE。

現場事件（都不預警）：
每天從 8 個事件（阿黃、田主阿伯、鐵牛車、廟公＋進香團、大冠鷲、阿嬤、徵收謠言、路邊停車）抽 3～4 個，每次玩都不一樣（抽到阿伯時，他會提醒的事一定也會發生）。選擇會連鎖到當天後面的事：
- 田主阿伯：在田裡（或菜園）佈標，他會從農舍走過來。道歉移點最好（他會順手把阿黃綁起來，還會順口提醒今天要注意的事，例如下午鐵牛車會經過）；拜託通融看運氣，硬拗失敗他會去找里長，飛到一半組長打電話來說里長投訴，報告記一筆；不理他，他會回農舍拖水管出來把標沖掉，也會去找里長。上次處得好，下次一到現場他就先來打招呼、把狗綁好；得罪過，下次一定會再遇到他，而且不給通融
- 阿黃：標做好之後漆要一段時間才會乾，阿黃會從農舍衝出來踩過去留下腳印（交通錐沒用）。可以叫學弟顧著還沒乾的標，或等漆乾；被踩了可以對著標按 E 補噴（花漆、又要重新等乾）
- 鐵牛車：中途會開進農路一趟；之後只要有標佈在農路上（或往廟埕的車道上），過一陣子又會再經過一次，所以一定會被輾出輪胎痕；擋在路上會被叭
- 廟公：只有把標佈在廟埕時才會出來，提醒下午有進香團。客氣道謝移點：作業車停廟埕沒關係，飛的時候他上二樓幫你看，大冠鷲來時會先大喊（QTE 時間比較寬）；敷衍他：飛到一半他會跑來叫你移車，航線中斷再續飛，正射影像會有接縫、空三誤差變大
- 進香團遊覽車：標都佈完、準備飛無人機的時候開進來，停在廟埕中間（被蓋住的標航拍就看不到）。作業車擋在農路或廟埕上，司機會下車叫你移車（廟公是朋友的話他會出來指揮，遊覽車就地停好）
- 徵收謠言：佈到第二個點左右，村民來問「是不是要徵收？」拿派工單好好說明就沒事；推給公所或說不知道，會引來一群鄉親圍著標看（站在標上航拍就看不到）；漆還沒乾的話會被踩出鞋印（要補噴、又要等乾）
- 路邊停車：標佈完後有台車開進農路，停在農路上的標上面，司機走進農舍。去農舍門口請車主移車，或放棄這個點；航拍時被車壓著就看不到
- 阿嬤：飛到一半走過來問「你在拍我家喔？」不理她，她會打給里長
- 學弟遞錯漆：噴黑漆時拿到的可能是白漆，噴下去發現顏色不對會跳出選項，可以叫學弟換一罐

## 三天一條線：人情、因果、尾聲

- 人情跨天：第三天的田主就是第一天問「是不是要徵收」的阿伯。第一天好好說明，第三天他一來就先綁狗、提醒你今天要注意的事；第一天亂講（第二天回訪也沒道歉），第三天噴到他的田就沒得商量。第一天頂撞地主／里長、亂動界樁推給阿姨，第三天村裡已經在傳你們要來徵收；拿公文、教阿姨申請鑑界，村民會主動說你們是合法的測量公司
- 同一個學弟：第三天的學弟就是第二天那位。第二天有發現他的尺沒立在標石頂上、當場教他、把尺墊拿給他，第三天他比較細心（收工比較不會漏東西）；都沒教，他更容易出包
- 每天的成果報告書最後有「這一天的因果」（你做了什麼 → 結果怎樣）和「如果當時……」（沒選的那條路會怎樣），第一次玩就看得到連鎖
- 第三天交差後有「尾聲：三天之後」：阿伯、里長、廟公、學弟、小朋友後來怎麼了，三天平均分數與組長的評語
- 重玩第三天時，會用上次第三天留下的人情

## 聲音
全部即時合成，不需要音檔：現場背景音樂（原創的逗趣小進行曲：低音管、撥弦、木魚；開車聽收音機時自動壓低）、環境音（風、蟬、鳥叫、靠近大馬路的車聲）、人物說話聲（阿伯低沉、小朋友尖細、對講機和電話是窄頻）、阿黃的吠叫。
M 鍵（或右上角「音量」、主選單「聲音設定」）可以分別開關背景音樂和音效、調整主音量／音樂／音效音量；T 鍵一次全部靜音。

## 操作
派工單上會列出當天要帶的設備。左邊的外業手簿按 J（或右上角「收起」）可以收起來／打開；拿手機拍照時會自動收起來。

| 走路 | 開車 |
|---|---|
| WASD 走動、Shift 快跑、滑鼠轉視角 | W 油門、S 煞車／倒車、A/D 轉向、Space 手煞車 |

## 存檔／讀檔
任何時候按 F6（或右上角「存檔」）把目前狀態存成文字檔；F7（或主選單「讀取存檔」）選檔接關。存檔時正在走路的 NPC 會直接到目的地；讀檔後進行中的對話或過場會從頭再來。

## 測試工具（F9）
任何時候按 F9：解鎖第三天、直接開始第三天；第三天現場可以一鍵佈好 5 個點（好位置／全踩坑）、佈標／RTK 畫面直接完成、準心位置直接佈一個標、每點補上 RTK 和照片、設定第一、二天的結果（地主／里長、阿姨、阿伯回訪、帶學弟）並解鎖第三天、直接看尾聲；立刻觸發阿伯／廟公／阿黃／鐵牛車／遊覽車／徵收謠言／鄉親圍觀／路邊停車／里長電話、收工時學弟一定忘鐵鎚、航拍直接完成、飛行中大冠鷲／阿嬤／廟公叫移車馬上來、重抽或全開事件池、設定人情（清除／全好／全壞）；設定「第一天的結果」（阿伯的回答、阿黃、小朋友）並解鎖第二天；直接開始某一天或直接到現場（設備自動裝好）；第一天一鍵架好儀器（定心定平完成，馬上觸發碰腳架事件）、阿姨馬上騎車來（直接切到收工）；在現場立刻觸發事件、一鍵整平、望遠鏡顯示正確讀數、讓學弟瞬移。

## 開發
需要 [Node.js](https://nodejs.org/) 20 以上。

```bash
npm install      # 第一次
npm run dev      # 開發：瀏覽器自動開啟，存檔即時更新
npm run build    # 產出 dist/index.html（單一檔案，雙擊即可遊玩、可直接分享）
```

技術：Vite + TypeScript + Three.js（r186）+ hls.js（廣播串流）。

## 結構
- `index.html` — HUD 骨架
- `src/main.ts` — 進入點；`src/globals.ts` — 給舊程式用的全域 THREE 相容墊片
- `src/legacy/` — 早期 JS 程式：程序化建模（`models.js`）、場景與地形（`scene.js`）、第一人稱操控（`player.js`）、流程（`main.js`）、各測量項目邏輯（`levels/`，目前主線用到 GNSS）
- `src/field/` — 外業一日（TypeScript）
  - `fieldDay.ts` 主控、`items.ts` 設備清單、`trunk.ts` 後斗格位規則、`truck.ts` 作業車與駕駛
  - `world.ts` 公司器材室、`nav.ts` 導航、`radio.ts` 車用收音機、`npc.ts` 車流與路人
  - `jobs.ts` 每天的派工內容與進度存檔
  - `siteEvents.ts` 第一天現場事件、`police.ts` 警車與警笛、`cine.ts` 登場運鏡與危險警示、`bench.ts` 儀器 3D 近距離操作
  - `gcpJob.ts` 第三天佈標（學弟、選點、平板、照片、成果）、`gcpEvents.ts` 第三天現場事件（事件池、人情）、`story.ts` 因果紀錄、`ending.ts` 尾聲、`rtkBench.ts` RTK 手簿、`uav.ts` 無人機航拍與正射影像、`gcpSite.ts` 第三天農地場景與地面分類、`gcpBench.ts` 噴漆與敲釘的 3D 近距離操作
  - `levelJob.ts` 第二天水準（學弟、測站、手簿、事件）、`scope.ts` 電子水準儀望遠鏡視野、`levelStaff.ts` 條碼尺與尺墊
  - `ui.ts` 介面、`sound.ts` 環境音／音樂／說話聲／狗叫、`saveload.ts` 存讀檔、`qte.ts` 小朋友 QTE、`fx.ts` 塵土與拍照特效、`look.ts` 轉向說話的人、`sfx.ts` 音效、`debug.ts` 測試工具（F9）
- `src/styles/` — 樣式（鍵帽 + 外業手簿視覺系統）
